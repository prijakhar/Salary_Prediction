# 💰 Employee Salary Prediction using Machine Learning

## 📌 Project Overview

This project predicts an employee's annual salary based on various professional attributes using Machine Learning.

The application is built using **Python**, **Scikit-learn**, and **Streamlit**, allowing users to enter employee details through a simple web interface and receive an estimated salary prediction.

This project was developed as an end-to-end Machine Learning project covering data preprocessing, exploratory data analysis, model training, evaluation, and deployment.

---

## 🚀 Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- One-Hot Encoding
- Data Scaling using StandardScaler
- Model Training
- Model Evaluation
- Streamlit Web Application
- Salary Prediction
